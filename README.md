# 老大最好了！！！ · 网页版

原来的 `老大最好了.py` 是 tkinter 桌面弹窗程序，只能在有桌面的电脑上跑。
这里换成了纯前端实现（HTML + CSS + JS），**在手机 / 电脑的浏览器里就能直接播放**，
再配一条内网穿透隧道，别人拿链接就能看到。

## 在线地址（已发布，长期有效）

- 页面：<https://miolawa.github.io/love-show/>
- 打开即自动播放：<https://miolawa.github.io/love-show/?auto=1>
- 源码仓库：<https://github.com/Miolawa/love-show>

托管在 GitHub Pages，免费、不用开电脑、不用隧道。想改内容就编辑本目录的 `index.html`，
然后二选一推上去：

- 在 GitHub 网页上打开 `index.html` → 铅笔图标 → 粘贴新内容 → Commit
- 或者把改动告诉我，我用脚本 `deploy-gh.mjs` 通过 API 推送（需要一个有 `repo` 权限的 token）

## 三个动画阶段

1. 心形：60 个「关心」弹窗沿心形轮廓依次出现
2. 满屏：96 个弹窗把屏幕均匀铺满
3. LOVE：39 个小弹窗拼出 L-O-V-E，然后停留 6 秒收尾

节奏、文案、字体大小都在 `index.html` 顶部的 `CFG` / `QUOTES` 里，直接改就行。

## 一、本机看

三选一：

- 双击 `index.html`（最简单，双击就能播，不需要服务器）
- 双击 `start-server.bat`，然后浏览器打开 <http://127.0.0.1:8000/>
- 命令行：`python server.py`（默认 8000 端口，`-p 9000` 可换端口）

带 `?auto=1` 打开会自动开始播放，适合发给别人：
<http://127.0.0.1:8000/?auto=1>

## 二、局域网看（同一个 Wi-Fi）

服务器启动后终端会打印「局域网」地址，例如 `http://192.168.1.10:8000/`，
手机连同一个 Wi-Fi 直接打开即可。

## 三、公网看（SakuraFrp，对应你截图里的「创建隧道」）

1. 先在本机把服务器跑起来：`start-server.bat`（或 `python server.py -p 8000`）
2. 回到 SakuraFrp 的「创建隧道」弹窗，按下面填：
   - 隧道名：`miol`（随便，已经填好）
   - 本地 IP：**留空**（留空就是 127.0.0.1，别填自己的公网 IP）
   - 本地端口：**8000**（必须和服务器端口一致，截图里那个红字报错就是这项空着）
   - 远程端口：**留空自动生成**
   - 隧道类型：`TCP 隧道` 就行（HTTP 隧道也可以，但 TCP 最省事）
   - 自动 HTTPS / 访问密码：先都禁用
3. 点「创建」，回到隧道列表，把这条隧道**启动**
4. 列表里会显示「远程地址」，形如 `cn-xx.sakurafrp.com:23456`
5. 浏览器打开 `http://cn-xx.sakurafrp.com:23456/` 就能看了；
   发给别人用 `http://cn-xx.sakurafrp.com:23456/?auto=1`，对方一打开就自动放。

> 截图顶部那个「公开游戏服务器穿透限制」是针对 MC / Palworld / ARK 这类游戏服的，
> 普通网页不受影响。隧道要一直「运行中」，关掉客户端或关掉本机服务，别人就打不开了。

## 四、换文案 / 调节奏

- 想加关心语录：改 `index.html` 里的 `QUOTES` / `SHORT_QUOTES` 数组
- 想快一点：把 `CFG` 里的 `*_STEP_MS`、`*_HOLD_MS` 调小
- 想心形更密：调大 `HEART_COUNT`；想更稀：调小
- 弹窗大小：`BIG_W` / `BIG_H`（手机会自动按屏宽缩放，不用管）

## 五、常见问题

- **端口被占用**：换端口 `python server.py -p 8080`，隧道里的「本地端口」也改成 8080
- **隧道连不上**：确认本机服务在跑、本地端口一致、防火墙放行；先在浏览器用 127.0.0.1 自测
- **手机上太小 / 太挤**：页面已按屏宽自动缩放弹窗和数量，横屏效果更接近桌面版
- **不想一直开电脑**：用上面的 GitHub Pages 在线地址即可，下面这些本地 / 隧道方式只是备用。
  如果哪天要在国内做更稳的访问，可以考虑备案域名 + 国内对象存储。
